## 五、P10-c 立项决策门（走查后拍板）

P10-c（单字段整文档，re-editor 式自绘 surface）**不是默认要做的**。它是为两件事服务的：
跨块选区的样式连续性（E17）与嵌套块拖拽。决策判据：

1. **B4/B5 全绿且 A3/A4 无不适** → 块级字段在 IME 上无恙，P10-c **缓立**；
   E17（跨块选区）与嵌套拖拽以"登记不装"继续存在，等真实使用痛了再立 ADR。
2. **B5 出现组合被打破 / 组合期 mark 错位且拦截层修不动** → P10-c **立项**：
   "IME 只见一个块"的完整版（施工表 §2 re-editor 三件技术：块域 IME 限定、controller 持
   TextInputConnection、结构相等 TextSpan 键控的 ui.Paragraph 缓存）。
3. **拖拽把手中 C1 的"中段嵌套"使用率极低** → 嵌套拖拽维持登记不装（文档操作已在）。

## 六、明确不在签收单上的

- E16（@提及/emoji/object 插入）：等 P6 对象身份面，编辑器内核无义务。
- HTML 粘贴、嵌套块拖拽、E17 跨块选区：ADR-0044 登记不装（除非第五节触发 P10-c）。
- 观感格的"好看"判断只属于真机；测试的绿色不为其背书。
