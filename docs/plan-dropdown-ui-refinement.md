## 2. 设计方案

### 2.1 模型选择器增强（P0）

**目标：** 将 `_ModelChip` 从纯文本 ID 列表升级为信息丰富的模型卡片列表。

**改动范围：**
- `lib/ui/conversation/composer.dart` — `_ModelChip` 重写
- `lib/state/model_directory.dart` — 扩展 `DirectoryModel` 增加描述/成本字段
- `lib/l10n/locales.dart` — 新增文案键

**设计方案：**

```
┌─────────────────────────────────────┐
│  默认          │  自定义              │  ← Tab 切换（可选，Phase 2）
├─────────────────────────────────────┤
│ ⚡ Auto         0.5×                │  ← 智能路由，带成本倍率
│   智能选择最适合的模型...             │
├─────────────────────────────────────┤
│ 🤖 Qwen3.8-Max  0.5×                │
│   千问最新一代基座模型...             │
├─────────────────────────────────────┤
│ 🤖 Qwen3.8-Flash 0.1×               │  ← 低成本选项高亮
│   千问开源权重的多模态...             │
─────────────────────────────────────┤
│ ️ 模型管理                          │  ← 跳转设置页
└─────────────────────────────────────┘
```

**实现要点：**
1. 菜单宽度从 260px 扩至 320px，容纳描述文本
2. 每个 `PopupMenuItem` 高度从 40px 增至 56px（双行：名称 + 描述）
3. 成本倍率右对齐，用 `DswType.xxxs11` + `labelTertiary`
4. 当前选中项左侧显示品牌色勾选图标（已有）
5. 底部固定"模型管理"行，点击跳转设置页模型节
6. `DirectoryModel` 扩展：增加 `description`（可选）和 `costMultiplier`（可选）字段
7. 当 provider 返回的模型列表无描述时，用模型 ID 派生简短描述（如 "OpenAI compatible endpoint"）

**不做的（Phase 2 再考虑）：**
- "默认/自定义"tab 切换（需要模型分组数据源）
- 低峰折扣提示条（需要计费 API 接入）
- 模型图标差异化（当前统一用 CPU 图标）

### 2.2 工作区状态栏 → 分支选择器（P1）

**目标：** 将工作区状态栏的分支名从纯文本展示升级为可交互的分支选择器。

**改动范围：**
- `lib/ui/conversation/composer.dart` — `_workspaceStatusBar` 增强
- `lib/host/git.dart` — 增加 `listBranches()` 方法
- `lib/l10n/locales.dart` — 新增文案键

**设计方案：**

```
┌─────────────────────────────────────┐
│  搜索分支                          │  ← 搜索框（可选，Phase 2）
├─────────────────────────────────────
│ 本地分支                             │  ← 分组标题
├─────────────────────────────────────
│ ✓ develop                            │  ← 当前分支带勾选
│   main                               │
├─────────────────────────────────────┤
│ ＋ 新建分支                           │  ← 操作入口（可选，Phase 2）
└─────────────────────────────────────┘
```

**实现要点：**
1. 点击分支名区域弹出分支列表（Overlay，复用 quick menu 的锚定模式）
2. 列表显示 `git branch --list` 的结果
3. 当前分支带勾选标记
4. 点击其他分支执行 `git checkout`
5. 切换后刷新状态栏显示

**Phase 1（最小实现）：**
- 仅显示分支列表 + 切换功能
- 无搜索框、无新建分支

**Phase 2（增强）：**
- 搜索框过滤
- 新建分支入口
- 远程分支分组

### 2.3 上下文压缩入口（P1）

**目标：** 在 Composer 或设置中提供对话上下文压缩的配置入口。

**改动范围：**
- `lib/model/app_settings.dart` — 新增 `contextCompression` 字段
- `lib/ui/settings/model_settings.dart` 或新建设置节
- `lib/genkit/agent_runtime.dart` — 投影时应用压缩策略
- `lib/l10n/locales.dart` — 新增文案键

**设计方案：**

在设置页新增"对话"节（或并入模型节）：

```
对话
├── 上下文压缩
│   ├── 关闭
│   ├── 保留首尾 + 最近 N 条    ← 推荐
│   └── 保留最近 N 条
└── 压缩阈值：当对话超过 __ 条时触发
```

**压缩策略（参考 kelivo）：**
1. **保留首尾模式**：始终保留系统提示 + 首条用户消息 + 末 N 条消息，中间消息摘要或丢弃
2. **滑动窗口模式**：只保留最近 N 条消息
3. **触发阈值**：对话超过 M 条时自动压缩

**实现要点：**
1. 在 `AppSettings` 中增加 `contextCompression` 配置（枚举 + 阈值）
2. 在 `agent_runtime.dart` 的投影逻辑中，构建消息列表时应用压缩
3. 压缩后的消息在 UI 中显示为折叠状态（可选）

## 4. 技术约束

- 所有下拉菜单继续使用 `PopupMenuButton` 或 `OverlayEntry`（与现有架构一致）
- 颜色/字号只从 `lib/theme/dsw_*` 取
- 文案同时进 `locales.dart` 双字典
- 不引入新依赖
- 分支操作通过 `Process.run('git', ...)` 实现（与现有 `_queryBranch` 一致）
- 上下文压缩在 `agent_runtime.dart` 的消息投影层实现，不改 Genkit 内核
